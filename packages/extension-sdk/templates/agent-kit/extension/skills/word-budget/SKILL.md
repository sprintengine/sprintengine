# Word budget

1. Ask for the budget if the request does not give one.
2. Write the text, then count its words with the `count_words` tool of the
   Word count MCP server this extension adds.
3. Over budget: cut the least needed sentence and count again. Never pad a
   text that is under.
4. Say the final count beside the text.
